Reto práctico: Deploy de una aplicación Python

Integrante: Juan Beltran

Servidor Ubuntu configurado con Nginx (Reverse Proxy) y Gunicorn (WSGI) para Flask.

Ubuntu Server Python 3 Flask Virtualenv (.venv) Nginx Gunicorn Systemd

1. Estructura del Proyecto

Organización de archivos en el repositorio y servidor: código fuente, entorno virtual, plantillas y archivos de dependencias.

2. Entorno Virtual Aislado (.venv)

Binarios y módulos de Python instalados de forma aislada dentro de .venv/bin sin afectar el entorno global del sistema operativo.

3. Servicios Activos del Sistema

Servicios miapp.service (Gunicorn) y nginx.service ejecutándose en estado activo (running) administrados por Systemd.
