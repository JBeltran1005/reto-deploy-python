Reto práctico: Deploy de una aplicación Python

Integrante: Juan Beltran

Infraestructura desplegada sobre Ubuntu Server. Tráfico enrutado vía Nginx Reverse Proxy hacia Gunicorn WSGI en entorno aislado.

Ubuntu 24.04 Python 3.12 Flask Virtualenv (.venv) Nginx Proxy Gunicorn Daemon Systemd Managed

1. Estructura del Proyecto

Árbol de directorios con templates, estáticos, dependencias y configuración CI/CD.

2. Entorno Virtual Aislado (.venv)

Binarios y paquetes instalados dentro del virtualenv local sin dependencias globales.

3. Servicios Activos del Sistema

Monitoreo de procesos en ejecución: miapp.service (Gunicorn) y nginx.service en Systemd.
